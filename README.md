# Odd-Even-Number-Detection
A program that asks you to toss in a whole number and plays detective to figure out if it's even or odd. It uses the handy modulo operator (`%`) to divide your number by 2 and check the leftovers. If there's zero remainder (`num % 2 == 0`), it celebrates an even number, and if anything is left over, it hits the `else` block and calls it odd!
